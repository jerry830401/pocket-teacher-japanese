# `/add-data` Skill 使用指南

這個 skill 用於為 PTJP 新增 JLPT 學習資料。執行後會依序：
1. 生成新資料（由 Claude 根據 JLPT 範圍產出）
2. 審查正確性（讀音、意思、文法自然度）
3. 寫入 JSON 檔案

---

## 使用方式

在 Claude Code 中輸入：

```
/add-data <type> <level> <count>
```

| 參數 | 說明 | 可用值 |
|------|------|--------|
| `type` | 資料類型 | `vocab`（單字）、`grammar`（文法） |
| `level` | JLPT 等級 | `N5`、`N4`、`N3`、`N2`、`N1` |
| `count` | 新增筆數 | 1–50（建議每次 10–20） |

### 範例

```
/add-data vocab N5 20      # 新增 20 個 N5 單字
/add-data grammar N5 10    # 新增 10 個 N5 文法題
/add-data vocab N4 15      # 新增 15 個 N4 單字（未來使用）
```

---

## 執行流程說明

```
讀取現有 JSON
    ↓
確認最大 ID 編號（避免衝突）
    ↓
Claude 生成新資料（不與現有重複）
    ↓
逐條審查（讀音、意思、文法正確性）
    ↓
有問題就地修正
    ↓
Append 寫入 JSON
    ↓
Python 驗證無重複 ID
    ↓
回報摘要
```

## 審查標準

### 單字（vocab）
- 讀音（reading）使用正確平假名
- 意思（meaning）符合該等級的常見用法，使用繁體中文
- 詞性（pos）分類正確：`noun`、`verb`、`i-adj`、`na-adj`、`adverb`
- 不與現有單字重複

### 文法（grammar）
- 例句（sentence）含且只含一個 `___`
- 答案（answer）必須出現在四個選項（choices）中
- 填入答案後句子文法正確且自然
- 干擾選項是同類型的助詞或語尾（具有合理迷惑性，不是隨意湊數）
- 翻譯（meaning）是填入答案後完整句子的繁體中文
